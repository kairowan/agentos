# Security Policy

AgentOS is pre-alpha software and is not suitable for sensitive or daily-driver use.

Report vulnerabilities using GitHub private vulnerability reporting. Do not open a
public issue for a working capability bypass, privilege escalation, data-scope leak,
confirmation spoof, generated-code escape, or verified-boot weakness.

The model is never a security principal. Model output, retrieved content, generated
workflows, and tool results are untrusted until checked at a typed system boundary.
